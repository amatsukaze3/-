# よみあげさん-jyohakyu-（五色百人一首 読み上げアプリ）

制作：福知山かるたWAVE

五色百人一首（20枚ずつ5色）の読み上げアプリです。`index.html` 1ファイルで動きます（音声・画像もすべて中に入っています）。

- 色別・札えらび・練習／試合モード（試合は17枚＋同数なら決勝の1枚）
- 全部／上の句まで／上の句の5文字／決まり字＋1文字／決まり字だけ（決まり字は色の20枚の中で数える）
- 読み上げ音声：ちぃちゃん（VOICEVOX:琴詠ニア）／ ふっくん（VOICEVOX:玄野武宏）
- 利用規約はアプリ画面下の「利用規約」に記載しています
- タイムアタック（17枚を24秒／15秒／13秒で読む3コースと、よみかた・秒数を自分で決める「タイムアタックチャレンジャー」）
